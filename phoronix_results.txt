================================================================================
  LLM INFERENCE — llama-bench (llama.cpp b7751, ROCm HIP)

All models fully GPU-offloaded (ngl=99). pp512 = prompt processing 512 tokens,
tg128 = text generation 128 tokens.

| Model                            | Size     | Params  | Quant   | pp512 (t/s) | tg128 (t/s) |
|----------------------------------|----------|---------|---------|-------------|-------------|

--- With Flash Attention (fa=1) ---

| Model                            | Size     | Params  | Quant   | pp512 (t/s) | tg128 (t/s) |
|----------------------------------|----------|---------|---------|-------------|-------------|
| Qwen3-14B                        | 8.38 GiB | 14.77 B | Q4_K_M  | 2,038.3     | 53.2        |
| Qwen3-30B-A3B (MoE, 8/128 exp)  | 17.28 GiB| 30.53 B | Q4_K_M  | 2,865.0     | 89.3        |

Flash Attention Impact (Qwen3-30B-A3B):
  pp512: 348.6 -> 2,865.0 t/s  (8.2x speedup)
  tg128: 77.3  -> 89.3 t/s     (1.16x speedup)

Notes:
  - Qwen3-30B-A3B is a Mixture-of-Experts model: 30.53B total params, ~3B active
  - 128 experts, 8 active per token — extremely efficient for its capability
  - The MoE architecture benefits massively from flash attention on prompt processing
  - At 89.3 tok/s generation with FA, this is faster than the dense 8B model

================================================================================
  FAILED MODEL ANALYSIS
================================================================================

Qwen3-30B-A3B-Thinking-2507-Claude-4.5-Sonnet-High-Reasoning-Distill:
  - Architecture: qwen3moe (same as working model)
  - GGUF version: v3
  - Error: "failed to load model" — likely requires newer llama.cpp for
    thinking/reasoning token extensions
  - Workaround: Use standard Qwen3-30B-A3B instead

GPT-OSS-20B MXFP4:
  - Uses MXFP4 quantization format not supported by llama.cpp b7751
  - May require updated GGUF support

Qwen2.5-Coder-32B Q4_K_M:
  - Model size (~19 GiB) exceeds available VRAM when other processes active
  - Would work with full 32 GB VRAM available
